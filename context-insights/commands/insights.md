---

请使用 `context-insights` MCP 服务器的 `context_insights` 工具生成跨会话用量报告：

- 默认 **精简模式**：传 `range: "7d", brief: true`（KPI/模型分布/工作区分布/会话榜），避免长报告挤占会话窗口。
- 用户明确要"完整报告"时再去掉 brief（含每日柱、8 周热力图、小时分布、工具/技能/文件/命令四账本）。
- 用户指定了时间范围（今天/30 天/全部）、工作区路径或关键词时，传入对应 `range` / `workspace` / `query`。
- 把工具返回的 Markdown **原样**呈现，并在最前面补一行总览（会话数、请求次数、总 token、成本折算、缓存省钱额）。
- 若返回"没有请求记录"，改用 `range: "all"` 重试一次；仍为空则如实告知。
- 结尾可补一句观察（如峰值时段、最费会话、命中率），但不要编造工具未返回的数字。
