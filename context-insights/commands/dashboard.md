请立即调用 `context-insights` MCP 服务器的 `dashboard_show` 工具（不传参数，或按用户指定传 range/workspace/query），把面板打开。**不要**再额外生成大段文字报告——看板本身就是交付物。

- 调用后按工具返回的文本简短确认（一两行：会话数/请求/token/成本即可）。
- 若宿主没有弹出面板/应用卡片（部分宿主版本不支持 UI 资源渲染），告知用户可用 `context_report` 生成 HTML 报表浏览器打开，并保留工具返回的摘要文字作为本页信息。
